# Shadow Protocol - Level Design Template

## Chapter 1: The Awakening - Underground Lab

### Level Layout
```
┌─────────────────────────────────┐
│  Main Laboratory                │
│  - Awakening Room               │
│  - Corridor Section A           │
│  - Medical Bay                  │
│  - Server Room (Key Location)   │
└─────────────────────────────────┘
```

### Objectives
1. Regain consciousness in the awakening chamber
2. Find the security override device
3. Access the server room for data on Eclipse
4. Escape via the emergency exit

### Enemy Placement
- 3x Patrol Drones in main corridor
- 1x Heavy Robot in server room (mini-boss)
- 2x Security Drones at exit

### Key Items
- Data Pad (quest item)
- Security Key Card
- First Aid Kit
- Pistol + 30 rounds

### Hidden Items
- Audio Log #1 ("Project Genesis")
- Memory Fragment (about Dr. Chen)
- Upgrade Module (Weapon Damage)
